# SIBN DPS Scenario Model

Воспроизводимая модель прогноза дивиденда на акцию (DPS) ПАО «Газпром нефть» (MOEX: SIBN)
на 2026 год: Brent → netback → налоги → маржи МСФО → payout → DPS, с бэктестом на факте
2024/2025 и (в следующих итерациях) сценарным Монте-Карло.

**Статус: этапы 1-2 из 4.** Скелет, загрузчики данных, детерминированная модель Блоков 1-4,
бэктест Блока 5, историческая калибровка волатильности/корреляции и сценарный Монте-Карло
(base/escalation/hormuz, ≥10k путей) реализованы и воспроизводимо запускаются на реальных
данных. HTML-отчёт с графиками (этап 3) и точный НДПИ/демпфер (этап 4) — ещё не реализованы.
**Бэктест 2024/2025 сейчас НЕ проходит допуск ±15%** — см. «Известные ограничения» ниже,
это не скрыто, а явный диагностируемый результат.

## Быстрый старт

```bash
cd sibn_dividends
/opt/miniconda3/bin/python -m pip install -e ".[dev]"
```

Скопируйте `.env.example` в `.env` в корне репозитория (или используйте уже существующий
`.env` — `FINDATA_API_URL`/`FINDATA_API_TOKEN` уже туда добавлены) и заполните токен.

```bash
/opt/miniconda3/bin/python run.py                 # прогон модели + бэктест
/opt/miniconda3/bin/python -m pytest tests/ -v     # тесты
/opt/miniconda3/bin/python -m ruff check .         # линт
```

Первый запуск дёргает Financemarker API, ЦБ РФ (курс) и FRED (Brent); дальше всё берётся
из локального кэша `data/cache/` (TTL настраивается в `config/assumptions.yaml`).

## Структура

```
src/data/       — клиенты источников данных (Financemarker, ЦБ РФ, Brent/FRED, Urals-manual)
src/model/      — Блок 1 (netback), Блок 2 (налоги), Блок 3 (маржи), Блок 4 (дивиденд),
                  Блок 5 (бэктест)
src/scenarios/  — калибровка волатильности/корреляции, копулы, Монте-Карло, сценарии YAML
config/assumptions.yaml — ВСЕ числовые допущения модели
config/scenarios/{base,escalation,hormuz}.yaml — сценарные допущения
data/cache/     — локальный кэш API-запросов (gitignored)
data/manual/    — CSV-заглушки для источников без надёжного API (Urals Минфин)
tests/          — pytest: налоговая прогрессивность + бэктест 2024/2025
run.py          — CLI-точка входа
```

## Источник финансовых данных

Клиент (`src/data/findata_client.py`) работает со сторонним провайдером
**Financemarker** (`financemarker.ru/api`) — это и есть источник, на который ссылалось ТЗ
(«мой корпоративный API»); рабочий пример был найден в `Instruments/DCF/my_dcf.ipynb`.
Токен сейчас также захардкожен и закоммичен в этом ноутбуке (git history, коммит `3f0897a`) —
**рекомендуется ротировать токен** у провайдера, раз он теперь и так публично виден в истории
репозитория; в новом коде токен читается только из `.env` (не в git).

## Словарь допущений и известные упрощения

- **Единицы**: все денежные величины внутри модели — в млн ₽ (как у Financemarker `reports`).
- **DPS фискального года**: `S1(year=Y) + Y(year=Y+1)` (не поле `year` из API напрямую —
  оно ненадёжно для самой свежей записи). См. docstring `dividends_by_fiscal_year`.
  Проверено точным совпадением с фактом 2025 (45.41 ₽) и 2024 (79.17 ₽).
- **Upstream/downstream split (Блок 1)**: физическая модель по объёмам (`operations`),
  т.к. в источнике нет посегментной выручки в ₽. Есть разрыв раскрытия: детальные
  `oil_production/gas_production` — до 2020 включительно; 2021-2022 — нет данных вообще;
  2023-2025 — только агрегированный `hydrocarbon_production` (нефть+газ) и `oil_refining`.
  Использовать `original_value * original_amount` для физической величины в тоннах —
  поля `value`/`amount` по-разному масштабированы между старыми и новыми метриками
  (проверено на реальных данных, см. `netback._true_tonnes`).
- **Драйвер регрессии маржи (Блок 3)**: НЕ полная формула netback (Brent-дисконт-фрахт)×FX,
  а более простой и полностью доступный **Brent×USDRUB** (без вычета дисконта/фрахта).
  Причина: исторического ряда дисконта Urals-Brent нет (см. Urals ниже), а собственные
  объёмы добычи SIBN имеют разрыв методологии на границе 2021-2023. Прогнозный расчёт
  использует тот же (Brent×USDRUB) driver для консистентности между калибровкой и
  прогнозом.
- **Налоговый клин (Блок 2, fallback)**: НЕ откалиброван регрессией на отчётности SIBN,
  как в исходном ТЗ, — в `reports` нет отдельной строки НДПИ/экспортной пошлины
  (`cost_of_sales` есть только за 2025, `cash_paid_for_tax` всегда `null`). Используется
  иллюстративная функция порог+предельная ставка с параметрами из публичных оценок
  налогового клина по Urals. Свойство прогрессивности гарантировано формой функции и
  проверено тестом (`tests/test_tax_progressivity.py`), а не подогнано под факт.
- **P&L waterfall (Блок 3/4)**: EBITDA-маржа — из регрессии на price driver; D&A%, ставка
  по долгу, эффективная ставка налога на прибыль, доля миноритариев — среднее за последние
  `waterfall.trailing_years` (3) отчётных года (не price-driven — это структурные величины).
  Причина отказа от прямой регрессии NI-маржи на price driver: она давала ошибку
  бэктеста +70-121% (не видела эффекта роста долговой нагрузки, Net Debt/EBITDA
  0.29x→1.43x за 2021-2025) — bottom-up waterfall с процентами на модельный долг снизил
  ошибку, но не устранил её (см. ниже).
- **Ставка по долгу**: среднее `interest_expense/net_debt` за 3 года — блендированная
  балансовая ставка по накопленному долгу, НЕ маржинальная стоимость нового займа (та
  выше, ~16%, судя по `Instruments/DCF/my_dcf.ipynb`).
- **Urals (Минфин)**: `data/manual/urals_minfin.csv` — пустая заглушка, заполняется вручную
  (нужна только для точного НДПИ, этап 4, не для fallback-режима MVP).
- **Brent**: источник по умолчанию — FRED (`DCOILBRENTEU`), не Stooq. Stooq теперь требует
  JS-верификацию бота и недоступен для скриптового запроса (проверено вживую).

## Сценарии и Монте-Карло (этап 2)

`src/scenarios/calibration.py` оценивает волатильность и корреляцию Brent/USDRUB на дневных
данных с 2022 года (не экспертно) и сравнивает хвостовую вероятность совместного движения
(«нефть вниз, рубль слабее») между гауссовой копулой и t-копулой. **Эмпирический вывод:**
корреляция Brent-USDRUB за 2022–2026 слабая и слегка ПОЛОЖИТЕЛЬНАЯ (+0.06) — тезис «рубль как
встроенный амортизатор» на дневных лог-доходностях данными явно не подтверждается (вероятно,
из-за нерыночного валютного режима после 2022: обязательная продажа валютной выручки,
капитальные ограничения). t-копула даёт более толстый хвост (1.31% vs 0.83% у гауссовой),
что ближе к эмпирике (1.26%) — свидетельство в пользу t-копулы. Тем не менее сценарии
`escalation`/`hormuz` закладывают ослабление/укрепление рубля через `fx_shift_multiplier`
СТРУКТУРНО (иллюстративно, по логике бюджетного ограничения), а не из этой слабой эмпирической
корреляции — расхождение явно отмечено в выводе `run.py`, не скрыто.

`src/scenarios/montecarlo.py` симулирует Brent/USDRUB как коррелированное дневное случайное
блуждание без сноса (без «мнения» о направлении сверх сценарного сдвига уровня) на год вперёд,
берёт среднегодовую по каждому пути и прогоняет её через ту же регрессию маржи и waterfall,
что и бэктест. Дисконт Urals-Brent сэмплируется независимо (треугольное распределение
min/base/max) — совместная историческая калибровка с Brent/FX недоступна без ряда Urals
(см. urals_minfin.py). Шок объёма переработки (`escalation`: -20%) входит в выручку через
долю downstream в физической netback-модели (Блок 1) на последних факт. объёмах.

Три сценария в `config/scenarios/*.yaml` держат ОДИНАКОВЫЙ базовый уровень Brent ($74.5,
Urals ~$54.5 при дисконте $20) для `base`/`escalation`, чтобы различия в DPS шли от
дисконта/переработки/курса, а не от произвольно разных цен; `hormuz` — блендированный годовой
эквивалент полугода на пике ($90-116 Urals) и полугода возврата к base (≈$99).

## Известные ограничения — бэктест не проходит ±15%

```
FY2024: факт 79.17 ₽, модель 117.94 ₽ (+49.0%)
FY2025: факт 45.41 ₽, модель 78.64 ₽ (+73.2%)
```

Разложение (см. `run.py`/`pytest -v` вывод): ошибка почти целиком в переоценке EBITDA-маржи
(+5.9…+6.6 п.п.) и особенно NI-маржи, а не в payout (75% в обоих случаях — Net Debt/EBITDA
не превышал 1.5x порог в LOO-раскладе). Регрессия EBITDA-маржи на n=5 точках (2021-2025) с
исключением тестового года имеет R²=0.13-0.60 — маржи SIBN снижались в 2022-2025 сильнее,
чем объясняет один только рублёвый Brent (вероятно — рост капиталоёмкости: D&A/выручка
7.4%→13.3%, и рост стоимости обслуживания долга; т.е. структурный сдвиг издержек, а не
чисто ценовой эффект). Пробовал добавить линейный тренд по годам вторым регрессором —
на n=4 (после LOO) это 1 степень свободы, регрессия становится нестабильной и в одном
случае ухудшает прогноз — отклонено как переобучение.

**Это не подогнано молча под факт** — оставлено как открытый, продемонстрированный тестами
результат для обсуждения: расширить окно калибровки на квартальные данные (доступны в
Financemarker, но с разрывом 2022-2023), либо перейти к точному НДПИ/демпферу раньше
запланированного этапа 4, либо явно моделировать тренд издержек отдельной переменной.
